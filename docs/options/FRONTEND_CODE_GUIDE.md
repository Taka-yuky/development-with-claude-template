# FRONTEND_CODE_GUIDE.md

フロントエンドのコードを **読む・書く・変更する** ときのガイドです。
ディレクトリ構成は `FRONTEND_STRUCTURE.md` を参照してください。
このドキュメントでは「なぜこの構成なのか」「どう動いているのか」を説明します。

---

## 1. レイヤー構成

【要記入】レイヤーの図と依存方向のルール。以下は例。

```
Page  （pages/）          ルーターが呼ぶ。状態管理・データ取得を担当
 └─ View / Component      表示を担当。propsで制御される
API層 （api/）            バックエンド呼び出しを関数として提供
共通  （types/ lib/ 等）   複数箇所で使う型・ロジック
```

**原則: 上位レイヤーは下位レイヤーに依存してよいが、逆は禁止。**

---

## 2. 状態とデータフロー

【要記入】どこで状態を持ち、どう子へ渡すか。URLで管理する状態があれば明記する。

---

## 3. 認証フロー

【要記入】トークンの保持場所・リフレッシュ・ガード（未認証時のリダイレクト）の仕組み。
方式の選定理由は `adr/` に記録する。

### APIリクエストの書き方

`api/` の関数を使い、`fetch` を直接呼ばない。

【要記入】複数画面で共有しているモジュールとその使い方。
